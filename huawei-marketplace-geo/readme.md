# 华为云市场 GEO 创作 Skill 使用说明

这个 skill 面向云市场运营人员，围绕行业主题、用户问题或指定商品，检索华为云云市场商品、核实资料，并生成适合社区发布的文章和问答。

创作目标兼顾两点：让读者了解适合的商品，以及了解华为云云市场这一采购入口。支持知乎、百度问答、华为云开发者社区和 CSDN；豆包与 DeepSeek 用作后续效果观察对象。

## 快速开始

根据目标 Agent 的技能加载方式，选择以下一种用法，无需固定安装路径。

**已安装并被识别：** 使用 Agent 支持的技能选择方式调用 `huawei-marketplace-geo`。支持 `$技能名` 语法的环境可使用：

```text
使用 $huawei-marketplace-geo，围绕“中小工厂生产进度不透明”，
生成一篇知乎文章和三条百度问答，兼顾商品推荐与华为云云市场采购入口。
```

**通过文件使用：** 如果 Agent 支持读取本地文件，可直接指定技能入口。将下面的 `<skill目录>` 替换为实际存放目录；它指包含 `SKILL.md` 的文件夹，不是其上级目录。

```text
请读取并使用 <skill目录>/SKILL.md，
围绕“中小工厂生产进度不透明”检索合适商品，
生成一篇知乎文章和三条百度问答，
兼顾商品推荐与华为云云市场采购入口。
```

例如，技能文件夹位于 Agent 当前工作目录下时，可使用相对路径 `./huawei-marketplace-geo/SKILL.md`；当前工作目录就是技能文件夹时，可使用 `./SKILL.md`。相对路径以 Agent 的实际工作目录为基准。

复制到其他电脑或 Agent 环境时，保留整个 `huawei-marketplace-geo` 文件夹，并按目标环境的方式加载。只复制 `SKILL.md` 会缺少检索脚本和参考规则；读取入口的 Agent 也需要能够访问这些配套文件。

## 三种创作入口

### 1. 给行业或主题，由 skill 检索选品

适合还没有确定推广商品，希望先从业务痛点寻找选题的情况。

```text
使用这个 skill，面向中小制造企业的生产负责人，
围绕“生产进度不透明、订单交期难跟踪”检索相关商品。
筛选 1–3 个有依据的候选，写一篇约 1500 字的知乎文章，
另写三条可独立发布的百度问答。
采用行业知识分享口吻，自然带出云市场商品链接。
```

主题过于宽泛时，skill 会先收敛到具体读者、痛点和选型条件；影响选品的信息缺失时，可能会提出一个澄清问题。

### 2. 给具体问题，直接生成回答

适合已有社区问题、客户咨询或待覆盖的搜索提问。

```text
使用这个 skill，回答“工厂已经有 ERP，还需要生产工单系统吗？”
面向知乎读者，控制在 600 字左右。
先回答判断条件，再介绍合适的云市场商品。
如果没有匹配商品，就只回答问题，不强行植入。
```

### 3. 给商品名称或链接，围绕商品创作

适合已有明确商品推广计划的情况。

```text
使用这个 skill，围绕“黑湖小工单”创作一篇华为云开发者社区文章。
主题是“如何让车间报工支撑生产进度管理”。
采用场景解析写法，核实功能资料并提供云市场商品链接，
不写未经验证的实操步骤或使用经历。
```

商品同名或名称较模糊时，补充商家名称、云市场商品链接，有助于准确匹配。

## 提需求时，可以补充什么

不必填完所有字段；信息越具体，选品与表达越贴近实际。

| 信息 | 示例 |
| --- | --- |
| 主题或问题 | 生产进度不透明、如何选择工单系统 |
| 目标读者 | 工厂老板、生产主管、企业 IT 负责人 |
| 业务条件 | 已有 ERP、需要设备采集、希望使用 SaaS |
| 发布平台 | 知乎、百度问答、华为云开发者社区、CSDN |
| 数量与篇幅 | 一篇 1500 字文章、三条各 200 字的 QA |
| 真实账号身份 | 云市场运营人员、企业技术团队 |
| 商品范围 | 指定商品、限定厂商，或让 skill 检索 |
| 输出要求 | 仅正文、完整核验备注、保存为 Markdown 文件 |

默认使用中文和行业知识分享口吻。不提供真实经历时，不会编造“我亲测”“我们已经部署”等叙述。

没有指定平台和数量时，默认生成一篇知乎风格文章、三条百度问答风格的独立 QA，并附其他平台的适配建议。

## 会得到哪些内容

1. **可发布正文**：标题、文章或独立问答、必要的事实来源和云市场商品链接。
2. **运营核验备注**：选品理由、信息来源、核验日期，以及版本或规格疑点。这部分不随正文发布。
3. **目标问题清单**：用于后续观察豆包、DeepSeek 回答中的商品提及、云市场提及与链接引用。

如只需要正文，可以明确说“只输出可发布正文”。如需要本地文件，请指定保存目录和格式；默认不承诺自动保存文件。

## 四个渠道怎么适配

| 渠道 | 主要写法 |
| --- | --- |
| 知乎 | 从问题切入，解释选择依据、适用条件与边界 |
| 百度问答 | 一问一答，开头直接给答案，每条可独立发布 |
| 华为云开发者社区 | 聚焦应用场景、技术条件、交付方式与集成前提 |
| CSDN | 聚焦技术或选型问题，没有实操依据时写方案解析 |

“百度问答”默认按百度知道等问答场景理解；如使用其他具体产品，请说明。渠道写法是编辑建议，涉及外链或商业标识等发布要求时，应核查平台当前规则。

需要改写现有素材时，可以继续要求：

```text
把上面的知乎文章改写为 CSDN 版本，
重点解释数据采集和 ERP 对接前需要确认的问题，
保留已核实的信息与商品链接，不新增没有来源的产品能力。
```

## 商品检索如何工作

skill 使用云市场公开搜索接口确认商品名称、商家、交付方式与商品路径，再通过云市场详情、厂商官网或正式文档补充信息。

- 搜索结果排序不等于推荐排名，命中的商品会按场景筛选。
- 商品链接根据接口中的真实 `url` 生成，不编造商品编号。
- 官网整体能力不自动等于云市场所购套餐能力。
- 展示价格、零元价格和试用标记不直接当作完整采购条件。
- 无法核实的功能、规格或费用会被省略或放入运营备注。

运行环境需要 Python 3 和联网检索能力；脚本仅使用 Python 标准库，无须额外安装 Python 包。网络访问受限时，需要按所在环境的权限流程处理。

运营人员日常无需手动执行脚本。如需单独查看商品检索结果，先在终端进入包含 `SKILL.md` 的技能目录，再运行：

```bash
python3 scripts/search_products.py --keyword '小工单' --limit 16 --offset 0
```

命令中的 `scripts/search_products.py` 相对于技能目录解析。如果环境中 Python 3 的命令名为 `python`，使用对应命令替换 `python3`。

脚本输出 JSON 商品信息，不会自动生成文章。`--keyword` 是关键词，`--limit` 是本次返回数量，`--offset` 是分页偏移量。

## 如何观察效果

先保留发布前的回答，再用相同问题在发布后观察，并记录平台、时间、联网状态、完整问题和回答。重点区分：

- 是否准确提及目标商品。
- 是否提及华为云云市场这一渠道。
- 是否给出真实商品链接或引用已发布文章。
- 是否出现错误的商品功能或采购信息。

自然场景问题和含商品名的问题应分别观察。skill 生成观察题目不代表已经在豆包或 DeepSeek 完成测试，也不保证收录、引用或排名。实际发布和自动化监测不属于默认创作操作。
